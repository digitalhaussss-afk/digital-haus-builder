Tips untuk Canva

Cara memasukkan ke Canva

Untuk kalender atau gambar countdown (diam):

  1. Tekan Copy ke Canva / Copy gambar PNG, atau Download PNG.
  2. Di Canva tekan Ctrl+V / Cmd+V, atau Uploads → Upload files.

Untuk countdown yang terus bergerak (cara TickCounter):

  1. Hosting sekali saja. Buka app.netlify.com/drop, tarik folder builder (hasil ekstrak ZIP) ke halaman itu. Buat akun gratis agar situsnya permanen. GitHub Pages juga bisa.
  2. Salin alamat situs (mis. https://nama-kamu.netlify.app/) ke kolom Alamat builder.
  3. Atur desain countdown, lalu klik Copy ke Canva.
  4. Di Canva: Apps → Embed → paste link → Add to design. Countdown tampil bergerak saat desain dipublikasikan sebagai website / dipresentasikan / dibuka lewat link.

Penting: Canva tidak bisa menjalankan countdown dari gambar atau kode HTML mentah yang di-paste. Hanya link Embed yang bergerak. Desain Canva yang di-download sebagai PNG/PDF/video tetap menampilkan angka saat itu saja.
