Tips untuk Canva

Cara memasukkan ke Canva

Untuk kalender atau gambar countdown:

  1. Pilih desain di builder ini, lalu tekan Copy ke Canva atau Download PNG.
  2. Di Canva, buka desain, tekan Ctrl+V / Cmd+V, atau buka Uploads → Upload files dan pilih PNG.

Untuk countdown yang terus bergerak di website Canva:

  1. Tekan Live Widget HTML dan simpan file yang diunduh.
  2. Upload file HTML itu ke GitHub Pages, Netlify, atau hosting HTTPS agar memiliki URL publik.
  3. Di Canva, coba Apps → Embed, tempel URL widget, lalu publikasikan websitenya.

Penting: Canva tidak menerima kode HTML mentah di desain. Dukungan URL Embed bergantung pada sumber widget dan jenis desain; beberapa URL tidak bisa di-embed. Gambar PNG dan desain Canva yang di-download tidak dapat menghitung mundur secara langsung.
